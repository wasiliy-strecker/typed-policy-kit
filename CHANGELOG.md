## [0.1.0] - 2026-07-18

### Added

- Type-safe RBAC and contextual authorization core
- Default-deny and explicit-deny precedence semantics
- React provider, `Can` component, and policy decision hook
- Express 5 enforcement middleware with problem responses
- Framework-neutral policy assertion testkit
- Multi-tenant React and Express Team Console demo
- Dual ESM and CommonJS builds with declaration files
- Compile-time API tests, package validation, and GitHub release automation
